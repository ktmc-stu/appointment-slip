？使用与打印说明
  • 跨装置同步：在 js/config.js 填入 Firebase 配置后部署到 GitHub Pages，所有装置即时共享同一份清单；未配置时只保存在本浏览器。

  • 打印设置：纸张选 80 × 140 mm，边距「无」，缩放 100%，关闭页眉页脚。每张 slip 一页，底部固定附 Printed at …。
  • 建议用 Chrome / Edge 打印。
